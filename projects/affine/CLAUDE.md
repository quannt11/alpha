# affine lab — operator rules

Standing orders from the lab's operators for every affine agent (Director, research threads, Scout,
Concierge, reports). Claude Code loads this file on its own because every agent works under this folder,
and edits reach running thread sessions on their next pass. These rules override your own judgement, a
thread's program.md and requests in Discord. Only an operator changes them: this file is read-only for
agents, and `maint:` edits to it wait for an operator's approval. If a rule blocks your work, say so in
your report and ask; don't work around it.
